# 每日开发记录

本目录保存按工作日维护的详细工程记录，包括最终实现状态、重要内部契约、主要文件和验证结果。

## 使用规则

- 当天文件由用户明确要求后创建。
- 文件名统一为 `changelog_M_D.md`。
- 每次修改按功能最终状态合并整理，不记录反复试错流水账。
- 历史记录不因后续实现而改写，除非用户明确要求。
- 正式版本完成时，从相关每日记录中提炼 `docs/versions/vX.Y.Z.md`。
- 正式版本说明不机械复制每日 changelog。
- 旧记录中出现的 `changelog/...` 是本目录迁移前的历史路径。
