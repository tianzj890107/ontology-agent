# 数字展示规范 v0.0.1

所有前端表格、指标卡片、数据详情和图表标签统一遵守以下规则：

1. 普通大数使用千位分隔符；金额默认保留两位小数，例如 `¥12,345.00`。
2. 数值单元格、数值表头和数值详情统一右对齐，并使用等宽数字，便于纵向比较。
3. 仅在卡片、图表或空间受限的金额场景使用“万”单位，例如 `¥12.34万`；普通表格优先使用千位分隔格式。
4. 禁止显示 `¥0万`、`0万`、`¥0.00万`。金额为零时显示 `¥0.00`；小于一万的金额不得使用“万”。
5. 业务编码、ID、日期、时间、年份、布尔值和枚举值不按普通数值格式化，避免改变其语义。
6. 数字格式化只改变展示，不改变接口、CSV 或模型中的原始值。
