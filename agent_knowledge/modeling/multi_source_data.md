1. 文档说明
1.1 编写目的
---
本文档基于「智能建模任务」交互原型，描述该功能的产品需求、页面结构、业务
流程、字段规则及验收标准，供产品设计、研发、测试与验收使用。
1.2 适用范围
---
• 统一管理五类智能建模任务：数据源建模、源代码建模、系统页面建模、业务
文档建模、自然语言建模
• 支持任务创建、查询、修改、删除、执行与结果阅览
• 四类建模（除自然语言建模外）在本页面内完成向导配置、智能体执行与结果
展示
• 自然语言建模跳转至独立页面完成
1.3 术语说明
---
Hub 页：指智能建模任务统一入口页，汇聚多路径建模任务。
智能体：基于大模型的建模执行引擎，负责逆向解析、语义识别与本体草案生成。
生成结果阅览：任务成功后查看结构化建模产出（要素列表 + 可视化视图）的弹框。

2. 产品背景与目标

2.1 背景
---
本体平台在「构建」阶段提供多种智能建模路径。企业往往同时存在数据库、源代
码、业务系统 UI、制度文档及自然语言描述等多源输入，若分散在多个子功能中
管理，将造成任务割裂、进度不可视、结果难以整合。
2.2 产品目标
---
• 提供统一的智能建模任务中心，一站式管理多路径建模任务
• 标准化任务编码、状态流转与操作入口，降低使用门槛
• 任务成功后可直接进入「生成结果阅览」与「智能消歧与整合」
• 与「数据来源管理」等基础能力联动，复用已注册输入源
2.3 用户角色
---
本体构建工程师（主要用户）：创建建模任务、配置输入源、触发智能体执行、查
看建模结果。

5. 任务编码规则

任务编码由「类型前缀 + 6 位流水号」组成，系统自动生成，创建后不可修改。
前缀规则：
RM  - 数据源建模（Reverse Modeling，逆向建模）
SC  - 源代码建模（Source Code）
SP  - 系统页面建模（System Page）
BD  - 业务文档建模（Business Document）
NL  - 自然语言建模（Natural Language）
示例：RM000001、SC000001、SP000001、BD000001、NL000001

6. 任务状态与流转

6.1 状态定义
---
待执行  - 任务已创建，尚未触发智能体
执行中  - 智能体正在解析建模
成功    - 建模完成，可查看结果
失败    - 执行异常终止
6.2 状态流转
---
待执行 --(点击智能体执行)--> 执行中 --(用户确认完成)--> 成功
执行中 --(异常)--> 失败
说明：执行过程中智能体完成解析后弹出「确认」提示，用户点击确认后任务状态
变为成功；未确认前可继续对话补充说明。
6.3 编辑权限
---
仅「待执行」状态的任务允许修改配置；其他状态任务详情为只读。

7. 新建任务流程

7.1 选择任务类型
---
点击「新建任务」弹出类型选择框，五类卡片单选：
数据源建模    - 数据库 / 文件逆向建模
源代码建模    - Java / C++ / Python 源码
系统页面建模  - OLTP / OLAP 页面扫描
业务文档建模  - 制度 / 需求 / 流程文档
自然语言建模  - 对话式 AI 建模（确认后跳转自然语言建模.html）
除自然语言建模外，其余四类在本页打开统一分步向导。
7.2 向导步骤（按类型）
---
【数据源 / 源代码 / 系统页面建模】（4 步）
步骤1 基本信息：任务名称*、模型名称*
步骤2 选择输入源：从数据来源管理注册清单多选
步骤3 选择解析范围：数据表 / 模块 / 页面（按类型）
步骤4 解析要素：勾选要素类型 + 可选智能体提示词
【业务文档建模】（3 步）
步骤1 基本信息
步骤2 选择文档源
步骤3 解析要素 + 提示词
7.3 校验规则
---
• 任务名称、模型名称必填
• 至少选择一个输入源
• 数据源建模：至少选择一张数据表
• 源代码建模：至少选择一个模块/包
• 系统页面建模：至少选择一个页面
• 至少选择一种解析要素
7.4 创建结果
---
校验通过后生成任务编码，任务写入列表，初始状态为「待执行」，Toast 提示
「任务已创建，状态为待执行」。

8. 分类型配置详情

8.1 数据源建模
---
输入源来源：MySQL、Oracle、PostgreSQL、GaussDB、Hive 等已注册数据库。
步骤3：按已选数据源 Tab 切换，分别选择 Schema（如适用）与数据表，支持表
名搜索。
默认可解析要素：逻辑实体、业务属性、实体关系、业务对象。
8.2 源代码建模
---
输入源来源：Java / C++ / Python 等代码仓库。
步骤3：选择待解析模块/包，支持搜索。
默认可解析要素：API、动作、业务规则。
8.3 系统页面建模
---
输入源来源：OLTP / OLAP 业务系统入口。
步骤3：选择待扫描页面/菜单，支持搜索。
默认可解析要素：动作、逻辑实体、业务属性、实体关系、业务对象、指标、维度。
8.4 业务文档建模
---
输入源来源：Word、PDF、Excel、流程图等文档类来源。
默认可解析要素：逻辑实体、业务属性、实体关系、业务对象、活动、活动流、
业务规则、指标、维度。
8.5 自然语言建模
---
不在本页向导创建，选择类型后跳转至「自然语言建模.html」独立页面。
本页仅支持查看任务详情（跳转）及列表展示。

9. 任务详情与修改

点击操作列「任务详情」图标打开向导弹框，标题为「任务详情 · {任务编码}」。
待执行状态：各步骤可编辑，底部显示「修改任务」按钮，保存后更新列表。
非待执行状态：全部字段只读，步骤条可切换查看，底部仅「关闭」。
自然语言建模：打开详情时跳转至自然语言建模页面。

10. 列表操作说明

操作列按钮随任务类型与状态变化：
10.1 通用
---
任务详情（info 图标）：所有任务可用
10.2 待执行
---
智能体执行（橙色 robot 图标）：触发建模，状态变为执行中，打开智能体工作台
10.3 执行中
---
智能体执行中（紫色 pulsing robot 图标）：打开工作台查看进度
10.4 成功
---
执行结果（青色 robot 图标）：查看智能体执行摘要（只读）
模型展示（eye 图标）：打开「生成结果阅览」弹框
消歧与整合（balance-scale 图标）：跳转智能消歧与整合.html
说明：自然语言建模成功任务不显示「模型展示」与「消歧与整合」。
10.5 失败
---
执行结果：查看失败摘要

11. 智能体执行工作台

11.1 布局
---
三栏结构：左侧历史会话 | 中间对话区 | 右侧 Canvas 预览
11.2 功能点
---
• 顶部进度条：展示执行进度百分比
• 对话流：系统消息、智能体消息、用户消息、产出卡片
• 产出卡片：点击后在 Canvas 查看详情（如表结构映射、实体关系草图、本体
模型草案）
• 输入框：执行中可补充解析指令；成功/失败后只读
• 新对话：执行中可新建补充会话
• 关闭窗口：不影响后台继续执行（提示文案）
11.3 确认机制
---
智能体完成解析后展示确认条：「智能体已完成本轮解析，请点击确认结束执行」。
用户确认后任务状态变为成功。
11.4 各类型执行阶段（示例）
---
数据源建模：
连接数据源 -> 识别实体属性 -> 表结构映射 -> 分析关系 -> 生成草案
源代码建模：
扫描模块 -> API 清单 -> 动作规则抽取 -> 过滤无关代码 -> 生成草案
系统页面建模：
加载页面 -> 页面清单 -> 字段属性识别 -> 关联实体 -> UI 草案
业务文档建模：
文档结构解析 -> 实体属性抽取 -> 规则提取 -> 文档草案

12. 生成结果阅览

成功任务点击「模型展示」在本页弹框打开，标题「生成结果阅览 · {任务名称}」。
底部按钮：关闭、消歧与整合（跳转整合页）。
12.1 数据源建模结果 Tab
---
逻辑实体、业务属性、实体关系、业务对象、可视化视图
12.2 源代码建模结果 Tab
---
API 服务、动作、业务规则、可视化视图
12.3 系统页面建模结果 Tab
---
动作、逻辑实体、业务属性、实体关系、业务对象、指标、维度、可视化视图
12.4 业务文档建模结果 Tab
---
逻辑实体、业务属性、实体关系、业务对象、活动、业务规则、可视化视图
12.5 可视化视图
---
只读 ER 关系画布，支持拖拽平移、缩放、全屏，不可编辑节点。

## 多源数据建模.docx

> 来源文件：`rules/多源数据建模.docx`
> SHA-256（前12位）：`ee62b3ba2be6`

5.1 多源数据逆向建模

5.1.1 功能描述

面向已有成熟业务系统、结构化数据的场景，通过解析数据库、数据表、数据字段、关联关系，自动反向工程生成标准化本体模型初稿，以「真实落地数据」为基础构建本体。

5.1.2 支持数据源类型

主流数据库：MySQL、Oracle、PostgreSQL等关系型数据库

结构化文件：Excel/CSV数据表、数据库建表脚本

接口数据：业务API接口字段、数据结构文档【待确认】

5.1.3 核心解析生成规则

数据表映射为逻辑实体，精准匹配数据落地对象

数据表字段映射为业务属性，字段类型自动同步为属性数据类型（数值、字符串、日期等）

数据库主键、外键、关联索引，自动解析为实体关联关系，并识别一对多、多对一、多对多基数关系

自动过滤冗余字段、日志字段、技术字段和审计字段、无效扩展字段，剔除无效模型要素，保证本体模型初稿精简可用

自动识别或者补充逻辑实体的业务主键

从逻辑实体中向上提炼、聚合业务对象，提炼业务对象关系

支持多表批量解析，批量生成本体模型，适配大规模数据建模场景
