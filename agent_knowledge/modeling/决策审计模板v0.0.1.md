# 决策审计模板 v0.0.1

`mission-work/` 只生成以下五个决策审计 CSV，表头由服务端固定输出并严格校验：

## business_object_decisions.csv

```text
候选业务对象编码,候选业务对象名称,最终决策,R1状态,R1证据,R2状态,R2证据,R3状态,R3证据,R4状态,R4证据,R5状态,R5证据,确认问题,置信度
```

## relation_decisions.csv

```text
关系决策编码,源实体编码,目标实体编码,关系类型,源属性,目标属性,决策状态,证据类型,证据族,冲突,候选来源,需要确认
```

## rule_decisions.csv

```text
规则决策编码,规则名称,规则类型,规则来源,存在状态,验证状态,强制状态,有效性状态,违例数量,命中数量,总数量,比例,处置状态
```

## indicator_decisions.csv

```text
指标决策编码,候选名称,决策状态,公式状态,聚合语义,范围,单位
```

## logical_entity_decisions.csv

```text
实体决策编码,逻辑实体编码,实体角色,业务对象归属状态,业务对象编码,决策状态
```

`pending_confirmations.csv` 不再生成。待确认原因、确认问题和证据详情保留在对应决策记录及 `modeling_state.json` 中。五个审计 CSV 不输出 `evidence_ids`、`missing_evidence`；指标审计不输出 `grain`。
