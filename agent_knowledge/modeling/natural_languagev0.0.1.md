## 自然语言本体建模v0.0.1.docx

> 来源文件：`rules/自然语言本体建模v0.0.1.docx`

自然语言本体建模

整体布局：左右双栏一体化布局（左对话输入区 / 右本体预览画布区），单页面无需跳转，行业主流交互范式，适配 PC 端本体平台工作台；页面归属菜单：智能建模 > 自然语言本体建模。

一、页面整体分区说明

顶部全局操作导航栏

左侧：AI 对话建模面板（输入、会话历史、候选要素审核）

右侧：实时本体可视化画布（树形清单 + 图谱双视图切换）

底部全局操作栏（保存、导入）

二、分区块原型文字原型（可直接交付 UI/Figma 还原）

区块 1：顶部导航栏（通栏）

左侧面包屑：本体构建 / 智能建模 / 自然语言本体建模

中间下拉选择框：当前工作分支（草稿分支 / 测试分支 / 正式分支）

右侧功能按钮组：

加载行业模板（下拉：政务 / 金融 / 制造 / 零售 / 通信）

清空会话

帮助文档

全屏画布

区块 2：左侧面板（占页面 40% 宽度）

2.1 Tab 切换头（2 个 Tab）

Tab1：文本对话建模（当前激活）

Tab2：示例模板库（点击切换，内置电信、零售、物流标准业务描述一键填充）

2.2 会话历史区域（可滚动）

会话卡片样式，每条对话区分角色：

【用户】灰色气泡：用户输入的业务描述

【AI】蓝色气泡：

文字摘要：已抽取 XX 个实体、XX 个属性、XX 组关系

折叠面板：逻辑实体列表 / 业务属性列表 / 实体关系列表

每条条目携带：置信度（高 / 中 / 低）、操作按钮【编辑名称】【删除】

底部小字溯源：本次生成基于大模型语义抽取，来源：自然语言对话

多条历史上下记忆，AI 增量建模时自动读取历史本体上下文。

2.3 底部输入区（固定悬浮，不可滚动）

多行文本输入框，占位提示文案：

示例：搭建订单、用户、商品本体；一个用户可创建多个订单，订单包含商品，订单拥有订单金额、下单时间属性，金额必须大于 0

输入框下方快捷按钮：

【一键填充行业示例】｜【智能生成本体草稿】｜【追加修改指令】

区块 3：右侧面板（占页面 60% 宽度，双视图切换）

3.1 视图切换 Tab

Tab1：图谱可视化视图（默认）

Tab2：结构化清单视图（树形表格）

3.2 Tab1 图谱可视化视图

画布空白区域：自动渲染 AI 生成实体节点、关系连线

节点配色区分来源：蓝色 = 自然语言建模、绿色 = 数据库逆向、橙色 = 业务文档正向

画布基础操作：缩放、平移、框选、重置布局

右侧悬浮侧边工具栏（画布内）：

AI 智能补全本体

模型消歧与整合（一键跳转对应菜单）

校验模型冲突（标红重复实体、逻辑矛盾关系）

点击节点弹出浮窗：编辑实体名称、新增属性、新增关系、设置约束

3.3 Tab2 结构化清单视图

三栏表格：实体清单、属性清单、关系清单

每一行支持单行编辑、批量勾选删除，实时同步图谱画布。

区块 4：页面底部全局操作通栏

从左至右按钮：

保存草稿（自动存入版本管理）

与已有本体合并（可选择其他建模产出融合）

三、完整页面交互流程（原型配套交互逻辑）

用户进入页面，可手动输入业务描述，或切换 Tab 加载行业模板填充；

点击【智能生成本体草稿】，左侧 AI 输出抽取候选清单，右侧画布实时渲染图谱；

用户在左侧会话面板删除错误实体 / 修改名称，右侧画布自动同步更新；

可在输入框追加增量指令：“新增支付记录实体，订单与支付记录一对一关联”，AI 迭代更新模型；

校验模型无冲突后，底部按钮支持导入；

支持切换行业模板，一键在现有本体基础上叠加行业标准概念。
