# AI 工艺 - AI 对话界面设计规范

## 1. 视觉风格概述

### 设计语言
- **风格**: 深色主题 + 工业科技感
- **设计规范**: 参考 Semi Design + 自定义深色变体
- **整体氛围**: 专业、清晰、现代感

### 色彩系统

| 用途 | 颜色名称 | Hex 值 |
|------|----------|--------|
| 主色 | 科技蓝 | `#1a73e8` |
| 次色 | 深空灰 | `#1f1f1f` |
| 强调色 | 活力橙 | `#ff6d00` |
| 成功色 | 清新绿 | `#00c853` |
| 警告色 | 暖棕 | `#8d6e63` |
| 背景色 | 深黑 | `#121212` |
| 卡片背景 | 炭灰 | `#2d2d2d` |
| 文字主色 | 纯白 | `#ffffff` |
| 文字次色 | 灰白 | `#9e9e9e` |
| 边框色 | 暗边 | `#424242` |

### 字体系统
- **主字体**: "PingFang SC", "SF Pro Display", -apple-system, sans-serif
- **等宽字体**: "SF Mono", "Consolas", monospace
- **标题**: 16-20px, font-weight: 600
- **正文**: 14px, font-weight: 400
- **辅助文字**: 12px, font-weight: 400

### 间距系统
- **基础单位**: 4px
- **间距层级**: 8px, 12px, 16px, 24px, 32px, 48px
- **卡片圆角**: 12px
- **按钮圆角**: 8px
- **输入框圆角**: 8px

## 2. 布局结构

### 整体布局
```
┌─────────────────────────────────────────────────────────┐
│  Logo + 标题栏                                          │
├──────────┬──────────────────────────────────────────────┤
│          │  顶部流程条 (3步骤)                          │
│  左侧    ├──────────────────────────────────────────────┤
│  历史    │                                              │
│  对话    │  主对话区域 (消息列表)                        │
│  列表    │                                              │
│          ├──────────────────────────────────────────────┤
│          │  输入区域 (上传 + 输入框 + 发送)              │
└──────────┴──────────────────────────────────────────────┘
```

### 左侧边栏
- **宽度**: 280px
- **背景**: `#1a1a1a`
- **历史对话列表**: 每项显示标题 + 时间

### 顶部流程条
- **3个步骤指示器**: 橙色高亮当前步骤
- **步骤**: 接受需求 → 解析工艺 → 输出结果

### 主对话区域
- **用户消息**: 右对齐，蓝色背景气泡
- **AI消息**: 左对齐，深灰背景气泡
- **图片消息**: 圆角卡片展示
- **Loading**: 三点脉冲动画

## 3. 组件设计

### 消息气泡
- **用户消息**
  - 背景: `#1a73e8`
  - 文字: `#ffffff`
  - 圆角: 16px 16px 4px 16px
  - 最大宽度: 70%

- **AI消息**
  - 背景: `#2d2d2d`
  - 文字: `#ffffff`
  - 圆角: 16px 16px 16px 4px
  - 最大宽度: 85%

### 图片上传卡片
- **容器**: 圆角12px，带虚线边框
- **缩略图**: 圆角8px，最大高度200px
- **文件名称**: 显示在图片下方

### Loading 动画
- **三点脉冲**: 圆点直径8px，间隔100ms
- **颜色**: `#1a73e8`
- **动画**: scale 0.8→1→0.8，opacity 0.5→1→0.5

### 发送按钮
- **颜色**: 橙色 `#ff6d00`
- **hover**: 亮度+10%
- **图标**: 箭头或发送图标

## 4. 对话流程演示

### 流程状态

1. **初始状态**: 空白对话区，显示欢迎语
2. **上传图片**: 显示上传卡片 + 文件名
3. **发送中**: 显示用户消息 + Loading 动画
4. **AI回复中**: 显示打字效果或流式输出
5. **回复完成**: 完整消息展示
6. **多轮对话**: 滚动显示历史消息

## 5. 动画规范

| 动画 | 时长 | 缓动函数 |
|------|------|----------|
| 消息出现 | 300ms | ease-out |
| Loading脉冲 | 1200ms | ease-in-out (循环) |
| 按钮hover | 200ms | ease |
| 展开/收起 | 250ms | ease-in-out |

## 6. 响应式断点

- **桌面**: ≥1200px (完整三栏布局)
- **平板**: 768-1199px (隐藏左侧栏)
- **手机**: <768px (单栏，底部输入)
