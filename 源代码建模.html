本体构建 · 智能建模 · 源代码建模

能力说明

支持源码类型

  • 源代码文件：Java、C++、Python 等源程序文件
  • 支持 Git 仓库、本地目录或源码压缩包等多种提交方式
  • 支持在同一任务中混合提交多种语言的源码

核心解析生成规则

  • 从源程序中识别 API 接口，映射为本体 API 服务
  • 从源程序中识别功能特性/子特性，映射为动作（Action）
  • 从源程序中识别业务规则，映射为本体业务规则
  • 自动过滤系统管理、系统监控、运维管理等与业务流程无关的源代码
